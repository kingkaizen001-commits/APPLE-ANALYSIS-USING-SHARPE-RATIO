# Bridgaton Website Structure — Detail Assignment Map

This document assigns what content/details should go into each page in your proposed structure.

## HOME
Purpose: Executive overview + conversion entry point.

Put these details here:
- Headline + one-line value proposition.
- Primary CTA (Book Demo / Get Started / Contact).
- Top 3 offers summary cards:
  - Creative
  - Bridgaton OS
  - Security
- Social proof strip (client logos/testimonials).
- Quick “How it works” in 3–4 steps.
- Secondary CTA to pricing/contact.

---

## Creative
Purpose: Service category landing page.

Put these details here:
- Creative positioning statement.
- Service comparison table for Ads / Branding / Strategy.
- Process timeline (discovery → concept → execution).
- Portfolio preview tiles.
- CTA: Request Creative Audit.

### Creative → Ads
Put:
- Campaign types (Meta, Google, TikTok, etc.).
- Deliverables (copies, visuals, variants, testing cadence).
- KPI model (CPA, ROAS, CTR).
- Typical engagement scope (monthly management vs campaign bursts).

### Creative → Branding
Put:
- Brand identity package breakdown.
- Messaging framework outputs.
- Visual system deliverables (logo, colors, typography, templates).
- Example before/after brand transformations.

### Creative → Strategy
Put:
- Go-to-market strategy deliverables.
- Audience and competitor analysis framework.
- Channel playbook outputs.
- Quarterly planning + reporting cadence.

### Creative → Pricing
Put:
- Packages (Starter / Growth / Enterprise).
- What is included per package.
- Add-ons and exclusions.
- Billing cadence and onboarding fee notes.

---

## Bridgaton OS
Purpose: Product suite landing page.

Put these details here:
- Product value proposition (unified operations layer).
- High-level module cards (POS, Multi-Branch, Analytics).
- Integration list (payment, inventory, accounting, APIs).
- CTA: Book Product Demo.

### Bridgaton OS → POS
Put:
- Core POS features.
- Supported hardware/devices.
- Checkout flow screenshots (later).
- Staff permissions and audit logs.

### Bridgaton OS → Multi-Branch
Put:
- Branch management capabilities.
- Centralized inventory/reorder capabilities.
- Role hierarchy by branch.
- Inter-branch transfer workflows.

### Bridgaton OS → Analytics
Put:
- KPI dashboard categories.
- Forecasting/optimization highlights.
- Report export/API capabilities.
- Executive summary examples.

### Bridgaton OS → Pricing
Put:
- SKU/location/user based pricing model.
- Tier comparison matrix.
- Implementation/support plan options.
- Enterprise custom quote path.
